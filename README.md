# Habit Tracker

## Overview
The Habit Tracker is a web application designed to help secondary and tertiary students manage their study and wellness habits. Users can log daily activities, track their progress over time, and receive motivational reminders to stay consistent.

## Features
- User authentication (login and registration)
- Profile management
- Habit logging with timestamped entries
- Weekly progress visualization through charts
- Customizable notification preferences
- Themed user interface (Day/Night/Nature)

## Technology Stack
- **Front-End**: 
  - React with TypeScript
  - Next.js for server-side rendering and routing
  - Tailwind CSS for styling
  - Recharts or Chart.js for visualizations
  - Workbox and Web Push API for notifications

- **Back-End**: 
  - Node.js with Express
  - PostgreSQL for database management
  - JWT for authentication

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/habit-tracker.git
   ```
2. Navigate to the project directory:
   ```
   cd habit-tracker
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Running the Application
To start the development server, run:
```
npm run dev
```
The application will be available at `http://localhost:3000`.

## Testing
To run tests, use:
```
npm test
```
